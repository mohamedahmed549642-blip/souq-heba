# سوق هبة | Souq Heba - متجر إلكتروني متكامل ونظام تتبع المخزون

منصة تجارة إلكترونية عربية متكاملة وحديثة، مخصصة لخدمة **كافة محافظات جمهورية مصر العربية الـ 27** حصرياً بالعملة الرسمية **الجنيه المصري (`ج.م` / EGP)** مع اعتماد **الدفع نقداً عند الاستلام (كاش فقط)**.

---

## 🚀 جاهز للربط مع: GitHub و Vercel و Firebase

تم تجهيز هذا المشروع بكامل الإعدادات والملفات المعيارية للنشر الفوري:
- **GitHub**: مستودع Git مهيأ بالكامل مع ملف `.gitignore` احترافي.
- **Vercel**: ملف `vercel.json` ومعالج الخادم اللامركزي `api/index.js` لنشر الواجهة والـ API بنقرة واحدة.
- **Firebase**: دعم Firebase Firestore و Firebase Storage و Firebase Hosting مع ملفات `firebase.json` و `.firebaserc` و `src/firebase.js`.

---

## 1️⃣ خطوات الربط مع GitHub

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم: `souq-heba` (بدون إضافة README أو .gitignore لأنها موجودة بالفعل).
2. افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:

```bash
git remote add origin https://github.com/abdelrahmanzagh/souq-heba.git
git branch -M main
git push -u origin main
```

---

## 2️⃣ خطوات الربط والنشر على Vercel

### الطريقة الأولى (الأسهل - التلقائية عبر GitHub):
1. ادخل على [Vercel Dashboard](https://vercel.com/dashboard).
2. اضغط على **"Add New Project"** ثم اختر مستودعك من GitHub: `souq-heba`.
3. اضغط **Deploy**.
4. يتعرف Vercel تلقائياً على Vite وExpress عبر ملف `vercel.json` و `api/index.js`.
5. في إعدادات المشروع (Settings > Environment Variables)، أضف المتغيرات الموجودة في `.env.example` (مثل `ADMIN_PASSWORD`).

### الطريقة الثانية (عبر Vercel CLI من موجه الأوامر):
```bash
vercel login
vercel
vercel --prod
```

---

## 3️⃣ خطوات الربط مع Firebase

المشروع مزود بمحول آمن (`src/firebase.js`) يتصل تلقائياً بقاعدة بيانات **Firestore** ومستودع **Firebase Storage** بمجرد إضافة بيانات مشروعك:

1. ادخل على [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً جديداً.
2. فعّل خدمة **Cloud Firestore** وضع القواعد المناسبة.
3. فعّل خدمة **Firebase Storage** لحفظ صور المنتجات المرفوعة سحابياً.
4. أضف تطبيق ويب (Web App) وانسخ إعدادات `firebaseConfig`.
5. أضف هذه القيم إلى ملف `.env` محلياً أو في **Environment Variables** على Vercel:

```env
VITE_FIREBASE_API_KEY=AIzaSy...
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

6. للنشر على **Firebase Hosting** مباشرة:
```bash
npx -y firebase-tools login
npx -y firebase-tools deploy --only hosting
```

## 🌟 مميزات المنصة الرئيسية

### 🛍️ واجهة متجر الزبائن:
- كتالوج المنتجات وتصنيفاتها: *عطور وعود*، *أزياء وعبايات*، *إلكترونيات*، *قهوة ومأكولات فاخرة*، *ديكور ومنزل*.
- مؤشرات المخزون اللحظية على كل منتج لمنع البيع الزائد عن رصيد المستودع.
- سلة تسوق ذكية تراعي حدود الكميات المتاحة في المخزون وتطبيق أكواد الخصم (`HEBA10`).
- نموذج إتمام طلب مخصص لمصر (محافظات مصر الـ 27، أرقام الموبايل المصرية، والدفع كاش).
- تتبع حالة الشحنات بالرقم أو الجوال بـ 4 مراحل.

### 🛡️ لوحة إدارة المتجر وتتبع المخزون:
- تتبع أرصدة المخزون والتزويد السريع (`+1`، `+5`، `-1`) ونافذة التوريد الكامل.
- سجل تدقيق حركة المخزون التاريخي (Audit Trail) لجميع المبيعات والتوريدات.
- إضافة وتعديل المنتجات مع رفع الصور من الجهاز مباشرة (سحب وإفلات أو اختيار ملفات) مع معاينة فورية.
- إدارة طلبات العملاء وتحديث حالات التسليم مع ميزة استرجاع المخزون عند الإلغاء.
